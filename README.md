# Smart Insurance Claim System

## ✅ Project Description
This decentralized smart contract allows users to submit insurance claims on the blockchain.  
The contract owner reviews each claim and approves or rejects it.  
If approved, the owner can pay the claim amount directly to the claimant securely on-chain.

## ✅ Project Vision
To replace traditional paper-based insurance claim processes with a transparent, fast, and trustless blockchain-based system.  
No middlemen, no delays — every claim is publicly visible and verifiable.

## ✅ Key Features
✔ Users submit insurance claims with amount & reason  
✔ Owner approves or rejects claims  
✔ Automatic payout directly to claimant’s wallet  
✔ Transparent & tamper-proof on the blockchain
